# A collection of useless articles and facts

Репозиторий для сбора, фактчекинга, глубокого анализа и опровержения фактов, заблуждений, законов и редких явлений.

Каждый материал проходит предварительную фильтрацию по протоколу критической верификации с опорой на первоисточники и фиксацией доказательной базы.

## Навигация
- [Правила верификации и работы (RULES.md)](RULES.md)
- `articles/` — подробные статьи и аналитические разборы.
- `facts/` — проверенные факты с подтверждающими документами.
- `debunked/` — опровержения популярных мифов и ложных утверждений.
- `laws/` — юридические казусы, необычные законы и правовые прецеденты.

## Принципы
1. **Строгая верификация**: Использование протокола `/rigorous-honest-critique`.
2. **Первоисточники**: Только проверяемые ссылки на законы, научные работы и архивы.
3. **Чистота репозитория**: Временные скрипты и дампы удаляются сразу после завершения проверки.
