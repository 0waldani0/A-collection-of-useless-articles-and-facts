# Закон: «Горький урок» Саттона, теорема Томаса—Дасгупты—Розинг и закон Амдала для гетерогенных ИИ-архитектур

## 1. Тезис / Формулировка законов
Попытки сконструировать конкурента универсальным большим языковым моделям (LLM) путем объединения множества специализированных ручных механизмов (гипервекторов HDC/VSA, символьных правил, графовых обходов на CPU и локальных векторных ядер на GPU) подчиняются трем строгим законам информатики и вычислительной техники:
1. **Эмпирический закон Ричарда Саттона («The Bitter Lesson», 2019)**: В долгосрочной перспективе архитектуры, построенные из множества вручную спроектированных когнитивных механизмов и доменных эвристик, неизбежно проигрывают гомогенным универсальным методам сквозного обучения (end-to-end learning) и поиска, которые эффективно масштабируются с ростом вычислительной мощности.
2. **Теорема Томаса—Дасгупты—Розинг о линейном пределе неградиентного HDC (JMLR 2021)**: Любая векторно-символьная система с фиксированным (случайным или заданным вручную) кодированием атомов и операциями связывания/суперпозиции без сквозного градиентного переобучения базы эквивалентна линейному классификатору в пространстве случайных признаков Рахими—Рехта и не способна преодолеть барьер нелинейного обучения представлений (Representation Learning).
3. **Закон Амдала для гетерогенных систем CPU + GPU (Amdahl, 1967; Gregg & Hazelwood, 2011)**: Ускорение гибридной системы из параллельных (GPU) и последовательных/ветвящихся (CPU) механизмов жестко ограничено долей последовательного кода и временем пересылки состояния по шине межсоединения:
   $$S_{\text{total}} = \frac{1}{(1 - f_{\text{GPU}}) + \frac{f_{\text{GPU}}}{S_{\text{GPU}}} + \frac{T_{\text{PCIe\_sync}}}{T_{\text{base}}}}$$

## 4. Подробный разбор механизма действия законов

### 1) Почему «множество различных механизмов» ломает масштабирование (Закон Саттона vs Закон Каплана)
В гомогенной LLM (трансформере) функция потерь кросс-энтропии $\mathcal{L}(\theta)$ дифференцируема по каждому из миллиардов параметров $\theta$ от выходного токена до первого слоя эмбеддингов. Согласно **законам масштабирования (Kaplan et al. 2020; Hoffmann et al. 2022)**, ошибка предсказания падает по строгому степенному закону при росте числа параметров $N$, объема данных $D_{\text{data}}$ и вычислений $C$:
$$\mathcal{L}(N, D_{\text{data}}) = E + \frac{A}{N^\alpha} + \frac{B}{D_{\text{data}}^\beta}$$
Когда же система собирается из разнородных недифференцируемых механизмов (таблиц, символьных парсеров на CPU, биполярных гипервекторов с $\text{sign}(\cdot)$, эвристических фильтров):
- Добавление 10 новых механизмов увеличивает комбинаторное число стыков и краевых ошибок пропорционально $\mathcal{O}(K^2)$ при $K$ механизмах.
- Ошибка на выходе системы не может автоматически скорректировать правила внутренних механизмов, так как градиент через дискретные структуры и клиппинг $\text{sign}(\cdot)$ равен нулю.

### 2) Численный расчет по Закону Амдала для связки CPU + GPU
Пусть гибридный ИИ выполняет один шаг вывода, в котором:
- $70\%$ операций составляют параллельные векторно-матричные вычисления на GPU (ускорение $S_{\text{GPU}} = 100\times$ относительно CPU);
- $30\%$ операций составляют последовательные символьные механизмы на CPU (обход графа по указателям, проверка логических условий, динамическая маршрутизация);
- На каждом шаге между CPU и GPU синхронно передается буфер промежуточных гипервекторов/состояний, добавляющий накладные расходы $T_{\text{PCIe\_sync}} = 0.20 \cdot T_{\text{base}}$.

Тогда реальное ускорение всей системы по закону Амдала составит:
$$S_{\text{total}} = \frac{1}{(1 - 0.70) + \frac{0.70}{100} + 0.20} = \frac{1}{0.30 + 0.007 + 0.20} = \frac{1}{0.507} \approx 1.97\times$$
Вместо ожидаемого $100$-кратного ускорения от использования GPU гетерогенная система из CPU- и GPU-механизмов получает менее $2\times$ прироста скорости, а $98\%$ вычислительной мощности GPU тратится впустую в ожидании последовательной фазы CPU и шины PCIe.

## 5. Ключевой вывод
Совокупность закона Амдала, теоремы Томаса—Дасгупты—Розинг и «Горького урока» Саттона устанавливает фундаментальный запрет на создание конкурентоспособного универсального ИИ методом механической сборки недифференцируемых алгоритмов на CPU и GPU: любая архитектура, разрывающая сквозной градиент и плотный матричный поток данных, проигрывает как по точности обобщения (из-за отсутствия глубокого обучения признаков), так и по аппаратной пропускной способности.
